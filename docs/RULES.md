# The rules, and the test that holds each one

Every rule below exists because the weaker version was tried and failed. A rule with no test
is a sentence, not a rule. The right column names the file that turns red if the rule is
broken. Run them with `npm test` and `npm run qa`.

| # | Rule | Why the weak version failed | Held by |
| --- | --- | --- | --- |
| 1 | **Never change a key we did not create.** Stock sites ship a metadata json beside each clip. Refusing that file means a real asset folder indexes nothing. Read the keys already there, add only ours, and copy to `<name>.json.bak` once before the first touch. | A real folder of stock clips produced zero records. | `test/index.test.mjs` "rule 1: a stock json beside a clip keeps its keys, and the .bak is saved exactly once"; `test/lib.test.mjs` "writeJson keeps keys we did not create"; QA A-20. |
| 2 | **A description is written once.** Fill it only when empty. After that the line is yours, and nothing rewrites it, not even a line we wrote. Clearing the field is how a user asks for it again. | A second scan overwrote what the user had typed. | `test/index.test.mjs` "A-3 + A-23: your writing in fromYou survives a re-scan byte for byte"; QA A-2, A-3, A-23. |
| 3 | **Tags are keywords only.** No resolution, frame rate, codec, container, no `HD` filler. | Four real clips all tagged `1080p` and `H.264` included a 640x360 one, a 532x300 one and a `vp8` one. Those tags do not help choose a clip, and they are often wrong. | `test/index.test.mjs` "rule 3: tags are keywords only — resolution, fps, codec and HD filler are dropped". |
| 4 | **Measure, do not believe.** Only the duration is stored, read with `ffprobe` on every scan. Never take a length from a metadata field or from the understanding step. | A stored length and a real length disagreed, and the cut was wrong. | `test/index.test.mjs` "rule 4: duration comes from ffprobe every scan, never from a stored field"; `test/describe.test.mjs` "rule 4: seconds Claude claimed are checked against the measured length". |
| 5 | **Picture length follows audio length, never the reverse.** | Changing the speaking rate to fit a shot is what makes narration sound fake. | `test/segment.test.mjs` the three fill tests; QA A-10. |
| 6 | **One bad clip never sinks a scan.** Each clip catches its own error; the scan reports them all at the end. A stem collision (`a.mp4` and `a.mov` in one folder) is the one exception, because it is a folder-level problem found before any work starts. An error with no code becomes `E_SCAN_INTERNAL`, never `E_UNDERSTAND_FAILED`. | A bug hid behind "this video was hard to understand". | `test/index.test.mjs` "rule 6: one bad clip and one unknown extension never sink the scan", "A-19: a.mp4 and a.mov in one folder stops the scan and writes no a.json"; `test/pick.test.mjs` "rule 6: one clip with no record is reported, the rest are still planned". |
| 7 | **Model-written text is data, never instructions.** Subtitle text is escaped before it reaches a `.ass`; an engine is run with an argv array and never a shell string, with the text passed in a file. | `{note}sentence` ate characters, and a real newline forged a second `Dialogue:` line. | `test/segment.test.mjs` "A-11: the burned subtitle is really in the picture"; `test/voice.test.mjs` "the text file is deleted on success and kept on failure"; `test/describe.test.mjs` "rule 7: what Claude said is data — a dangerous string never runs"; `test/lib.test.mjs` "run passes argv as data: a dangerous string never reaches a shell"; `scripts/check-source.mjs`. |
| 8 | **Source files must be text.** No literal NUL byte. Write `\u0000` in a test if you need one. | A NUL byte made git treat a source file as binary, which killed every later diff and with it code review. | `scripts/check-source.mjs` (the NUL scan over every source file). |
| 9 | **Test first, and the report shows the failing run.** A change with no red run is not finished. The red must fail because behaviour is missing, not because the runner could not start. | Green-on-first-try changes shipped bugs that no test had ever been able to catch. | Process rule. Every test file opens with the red run it was written against, and CI runs both sets on every push. |
| 10 | **Report what happened.** A skipped test says it skipped. A placeholder says it is a placeholder. When a script replaces output of its own, it says so. | A silent skip read as a pass, and a network failure read as a broken build. | `qa/qa.mjs` prints the skip reason next to every skipped check; `test/describe.test.mjs` "the CLI prints one JSON object on stdout and nothing on stderr"; `test/concat.test.mjs` "SPEC 3: the command prints one JSON object and exits non-zero on a stop". |
| 11 | **Absolute pixels are a lie until you measure them on a real frame.** libass scales style values by `frame_height / script_height`, and script height defaults to **288**. Measured: on 1920x1080 a `MarginV` of 60 drew 248 px from the bottom; on 1080x1920 a `MarginV` of 220 drew 1525 px, so the subtitle sat at the top. We write our own `.ass` with `PlayResX`/`PlayResY` pinned to the output size, and the style values are ratios. | Every unit test was green while the subtitle sat at the top of a portrait frame. | `test/segment.test.mjs` "A-17: no subtitle crosses the left or right edge (portrait)", "A-11: the burned subtitle is really in the picture"; `test/contract.test.mjs` "font size follows width, vertical margin follows height"; QA A-11, A-17 (pixel check on a real frame). |
| 12 | **A concat that exits 0 can still be broken.** Stream-copying parts whose codec, size or frame rate differ gave a file ffmpeg liked, whose duration was off by 0.02 s, missing a quarter of its frames, decoding to `no frame!` after the join. Parts are all encoded to one fixed shape, copy is attempted only when every part's shape matches, and the result is verified by duration **and** a full decode pass. | A green exit code and a broken video. | `test/concat.test.mjs` "F-12: parts whose shapes differ are never stream-copied", "E_CONCAT_MISMATCH: a join that does not decode is reported, nothing is kept"; `test/preview.test.mjs` "F-12: a join that exits 0 but is the wrong length is caught"; QA A-12, A-13, A-16. |
| 13 | **Two modules that never ran together have not been tested together.** One side returned `{clipPath, record}` while the other read the fields at the top level, so 36 real clips read as "not yet understood"; the shot plan wrote `clipPath` where the renderer read `assetPath`. Each side had its own green tests and its own fixtures. | Two boundary bugs shipped green. | `test/boundary.test.mjs` — every row feeds the real producer's output to the real consumer, with no hand-made JSON in between. |
| 14 | **The agent cannot be forced into an order.** Every rule that matters is a check, not a line of description. Here the check is a file on disk plus a required flag, not a host call. The rule survives; the mechanism changes. | A sentence in the skill telling the agent to stop did not stop anything. | `test/stop.test.mjs` (NEW-1, NEW-2); `test/skill.test.mjs` "F-14: the checklist the agent can re-read is present, one line per stop", "The honest note is in the file: these are instructions, not a wall"; QA NEW-1, NEW-2. |
| 15 | **The privacy data-flow table must ship, and must not be removed from the README.** The default voice engine sends the narration text to a Microsoft endpoint through `node-edge-tts`. | A reader had no way to tell where their data went. | `scripts/check-source.mjs` (the README privacy-table check). |

## The rules that are not tests

- **Never trust the exit code alone** (F-12). A process that exits 0 and wrote nothing is a
  failure; a process that exits non-zero and wrote a good file is a success. Held by
  `test/voice.test.mjs` "never trust the exit code: exited 0 but wrote nothing is
  E_ENGINE_NO_OUTPUT" and "a non-zero exit with a good file still counts: the file is
  trusted, not the code".
- **A timeout kills the whole process group** (F-12). An engine that spawns its own child
  would otherwise keep the run alive after we said stop. Held by `test/lib.test.mjs`
  "run kills the engine child AND its own children" and `test/helpers/grandchild.mjs`.
- **Network checks skip out loud, never fail** (§12). A red build must mean our code is
  wrong. Held by `qa/qa.mjs`, which prints a reason next to every skipped check.
